# 为什么当前 PD-PPO 不是最优版本：理论诊断

## 核心命题

当前提交的 PD-PPO（100k storm-window curriculum，协议修正版）是一个**协议合规的最小基线**，而非优化路线的终点。它的次优性不是随机噪声造成的，而是由四个相互独立的结构性原因决定的，每一个都有理论依据。

---

## 原因一：目标函数与真实损失之间存在系统性错位（Reward Misspecification）

当前 PPO 的奖励函数是 FW-MAE 的负值加上能量惩罚项。但 FW-MAE 本身是一个**事后聚合指标**：它对所有时间步的预测误差加权平均，而 blowing-snow event 期间的误差权重更高。

问题在于：PPO 在每一步收到的即时奖励是单步预测误差，而不是 event-period 内的条件误差。这意味着：

- 在非事件期（占大多数时间步），奖励信号密集但信息量低；
- 在事件期（真正需要优化的窗口），奖励信号稀疏且延迟；
- 策略梯度估计因此被非事件期的大量低信息样本稀释。

理论上，这等价于在一个**信号噪声比极低的奖励流**上做策略优化。PPO 的 clipped surrogate objective 在这种情况下会系统性地低估事件期的梯度贡献，导致策略在事件期的行为次优。

历史结果中 event reward multiplier 和 storm-window curriculum 的有效性正是这一诊断的实证支撑：storm-window curriculum 通过**重采样**提高事件期样本密度，相当于隐式地修正了奖励信号的信噪比。但它是一个采样层面的补丁，而非目标函数层面的根本修正。

---

## 原因二：状态空间中的预测信息未被充分利用（Partial Observability of Forecast Horizon）

PD-PPO 的核心设计是将 TCN oracle 的多步预测嵌入观测空间，使 agent 能够"预见"即将到来的 blowing-snow 事件，从而提前启动 warm-up。

但当前实现存在一个结构性限制：**oracle 预测的时间跨度与 warm-up 延迟的匹配程度未经优化**。

设 warm-up 延迟为 $\tau$ 步，oracle 提供未来 $H$ 步的预测。最优策略需要在 $t - \tau$ 时刻就决定是否启动 warm-up，以便在 $t$ 时刻事件发生时 laser 已就绪。这要求 oracle 在 $t - \tau$ 时刻对 $t$ 时刻的预测足够准确。

如果 $H < \tau$，oracle 根本无法提供足够超前的预警，策略退化为反应式而非预测式。如果 $H \gg \tau$，远期预测精度下降，噪声增大，反而干扰决策。

历史诊断中 laser event/non-event ratio ≈ 1.03×（几乎无事件触发分化）正是这一问题的症状：agent 并未学会利用预测信息提前切换，说明预测信号在当前状态编码方式下**未被有效提取**。这可能是 oracle 预测窗口与 warm-up 时序不匹配，也可能是预测特征在网络中被其他状态维度淹没。

---

## 原因三：能量约束的处理方式导致策略保守化（Constraint Handling Induces Risk Aversion）

当前 PPO 通过软惩罚项处理能量约束（abort penalty）。软惩罚的已知理论缺陷是：

**惩罚系数 $\lambda$ 的选择在 Lagrangian 对偶意义上等价于对约束违反的风险容忍度。** 若 $\lambda$ 过大，策略会过度保守，宁可放弃高信息量的 laser 激活也不冒 abort 风险；若 $\lambda$ 过小，约束违反频繁，训练不稳定。

在固定预算（B=1.70）下，约束实际上是非绑定的（static projection 消耗 1.46，margin=0.24），因此软惩罚对策略的扭曲效应被掩盖。但在能量账户场景（B=1.20，harvest=0.92），约束是真正绑定的，此时软惩罚的保守化效应直接压制了 laser 的动态激活频率。

历史结果中 SOC auxiliary critic 版本（storm 下 abort 降至 16，vs 当前 25.8）表明：通过显式建模 SOC 状态并将其纳入 critic 的价值估计，可以在不增加 abort 的前提下提高 laser 激活率。这是一个**约束感知的价值函数设计**，理论上对应于 Constrained MDP（CMDP）框架中的 Lagrangian 松弛方法，比当前的固定软惩罚更接近最优对偶解。

---

## 原因四：训练长度不足以收敛到策略空间的高质量区域（Sample Efficiency Bottleneck）

当前 100k 步训练在 storm-window curriculum 下对应的有效事件期样本数量有限。PPO 作为 on-policy 算法，每次策略更新后旧样本即被丢弃，样本效率本身就低于 off-policy 方法。

更关键的是：sensor scheduling 问题的状态空间包含 SOC 状态、warm-up 状态、多传感器组合状态，其有效维度随传感器数量指数增长。在 100k 步内，PPO 对这个空间的覆盖是稀疏的，尤其是在 SOC 接近约束边界的高风险区域。

历史结果中 300k seed41 的 storm loss 从 0.4106 降至 0.4053，laser event ratio 从 ≈1.03× 提升至 1.52×，直接证明了这一点：**更长训练使策略在约束边界附近的行为发生了质的变化**，从保守的固定子集退化转变为真正的事件触发切换。

这一现象在理论上对应于 PPO 的 policy improvement 在高曲率区域（约束边界附近）需要更多样本才能稳定收敛的已知特性。

---

## 综合诊断：次优性的结构图

```
当前 PD-PPO 次优性
├── 目标函数层面：事件期奖励信号被稀释（→ event reward multiplier / CMDP objective）
├── 状态利用层面：预测信息未被有效提取（→ 预测窗口与 warm-up 时序对齐）
├── 约束处理层面：软惩罚导致过度保守（→ SOC auxiliary critic / Lagrangian CMDP）
└── 训练充分性层面：100k 步不足以覆盖约束边界区域（→ 300k 训练 / off-policy 方法）
```

这四个原因在能量账户场景（B=1.20）下**同时激活**，因为该场景同时具备：约束绑定、事件稀疏、warm-up 时序关键、SOC 动态复杂。这解释了为什么固定预算（B=1.70）下 PD-PPO 表现尚可（约束非绑定，前三个原因的影响被压制），而能量账户场景下 PD-PPO 相对最强静态基线的优势不稳健。

---

## 对论文叙事的含义

这一理论诊断支持当前论文的保守主张：**当前 PD-PPO 是一个证明框架可行性的基线，而非该框架的最优实例化**。论文的贡献在于识别了"约束激活是动态调度价值的必要条件"这一 regime 条件，而非声称已找到最优策略。

上述四个改进方向（event-weighted objective、预测窗口对齐、SOC-aware CMDP、更长训练）构成了自然的 future work 路线图，且每一项都有当前实验结果作为动机证据。
