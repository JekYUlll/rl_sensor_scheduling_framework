## 3. 本轮核心问题清单

### 3.1 理论部分

#### 问题 T-1：Proposition 1 的证明对象是特权信息策略

高优先级。

Appendix A.2 构造的 `π*` 在每个时刻直接读取事件/制度标签 `c_t`。但 Table 4 明确写明：

> Event type labels: Online = No

因此当前 Proposition 1 实际证明的是：

> 存在一个能观察事件标签的 oracle dynamic policy，其 macro forecast loss 优于任何 fixed mask。

它没有直接证明：

> 可部署的 PD-PPO 优于 fixed mask。

这不是致命问题，但必须明确，因为命题应被定位为理论上界/设计依据，而 PD-PPO 是否能接近该上界应由实验回答。

#### 问题 T-2：Proposition 1 的前提需要实验验证

中优先级。

Proposition 1 的关键前提是：

> 不同事件制度的最优专家子集不兼容，没有一个 fixed specialist 能同时覆盖全部 positive-weight regimes。

当前正文主要凭直觉说明该前提。LEMMA 建议用 Table 11 中事件分解结果补充说明：event label replay 在 particle/flux/thermal 三个事件类型上均优于 fixed mask，从而支撑“没有单一 fixed specialist 同时最优”的经验前提。

#### 问题 T-3：Proposition 2 需要补充适用范围

中优先级。

Proposition 2 的构造是：

`y_{t+1} = c z_t + M e_t + η_t`, 且 `M >> c`。

该构造逻辑成立，但应明确：

- 这是 sufficient-condition / existence argument。
- 它证明 AoI/covariance 与 forecast loss 可以排序不同，而不是在所有系统中必然不同。
- 在当前 benchmark 中，flux 与 thermal 事件的事件敏感损失 gap 较大，可作为该机制的经验对应。

#### 问题 T-4：Appendix A.3 应说明 simple-cycle 假设不适用于当前 benchmark

低优先级。

Appendix A.3 讨论 fixed cycle 只有在 regime arrivals deterministic 且 phase-aligned 时才可能等价。当前 benchmark 的 blowing-snow events 由 semi-Markov process + wind exceedance 生成，应明确它们是 stochastic / non-periodic，并与 behavioural diagnostics 对应。

### T-1a. 替换 Section 3.2 中 Proposition 1 的全部文本

目标：明确 Proposition 1 证明的是 oracle dynamic policy / privileged diagnostic upper bound，而不是直接证明可部署 PD-PPO。

建议替换为：

```latex
\begin{proposition}[Dynamic value with one selectable specialist]
\label{prop:specialist_bottleneck}
Consider a scheduling problem with one selectable specialist in which at least two
regimes with positive evaluation weight have incompatible best specialist subsets.
If using a mismatched specialist subset in regime $c$ incurs excess forecast loss,
after normalisation by static references, of at least $\Delta_c>0$, then every
fixed specialist subset has strictly higher macro forecast loss than an oracle
dynamic policy $\pi^\star$ that observes the active regime label and selects
$S_c^\star$ accordingly.
\end{proposition}

A proof is given in \Cref{apx:specialist_bottleneck_proof}. The oracle policy
$\pi^\star$ requires direct access to the regime label $c_t$ at each step and is
therefore not deployable; it corresponds to the event label replay diagnostic in
\Cref{tab:baseline_reference_taxonomy}. The proposition establishes a theoretical
upper bound on the macro advantage available from dynamic specialist allocation.
Whether a learned policy can approach this bound from observable state evidence is
an empirical question answered by the benchmark. In the reported benchmark, the
incompatible specialists correspond to particle, flux, and thermal regimes. The
proposition is used as design rationale for the benchmark geometry; it is not a
claim that the same channel set or event mixture is universal.

\begin{remark}
The event label replay diagnostic implements $\pi^\star$ on held-out test
windows. Its mean macro margin over the fixed mask replay reference is 0.0773
(\Cref{tab:regime_balanced_24seed_summary}). The learned PD-PPO mean macro
margin is 0.0710, capturing approximately 92\% of the oracle advantage from the
available scheduler observation. This proximity confirms that the benchmark
contains exploitable adaptive structure and that the observable event context
proxies (\Cref{tab:online_observability_audit}) carry sufficient regime
information for a learned policy to approach the oracle bound. The gap between
$\pi^\star$ and PD-PPO, 0.0063 normalised units, represents the residual cost of
inferring regime context from noisy proxy signals rather than observing labels
directly.
\end{remark}
```

注意：原始 LEMMA 建议中引用的是 Table 5 / Table 10 / Table 4。当前 LaTeX 源中应尽量使用 label 引用：

- `\Cref{tab:baseline_reference_taxonomy}` for event label replay diagnostic / reference taxonomy。
- `\Cref{tab:regime_balanced_24seed_summary}` for 0.0773 / 0.0710 aggregate。
- `\Cref{tab:online_observability_audit}` for event labels not online。

### T-3a. 替换 Section 3.4 中 Proposition 2 之后的解释

```latex
The proof in \Cref{apx:non_equivalence_proof} uses a two-variable linear-Gaussian
construction in which the event sensitive variable has a large coefficient
$M\gg c$ relative to the background variable. The construction shows that when
event-period forecast loss is dominated by the event sensitive variable, a policy
that delays background refreshes to activate the event sensor can have strictly
lower forecast loss despite higher AoI and higher covariance trace. AoI and
covariance objectives are therefore not substitutes for a direct forecast loss
comparison when event sensitive channels exist; they are included as rule-based
dynamic references to provide non-learned dynamic comparators, not as equivalent
optimisation targets.

\begin{remark}
The non-equivalence result applies when the event sensitive variable contributes
substantially to forecast loss during event periods. In the reported benchmark,
the event type decomposition in \Cref{tab:event_type_loss_decomposition} shows
that the fixed mask reference has normalised losses of 0.870 and 0.906 in flux
and thermal regimes, while the event label replay diagnostic achieves 0.747 and
0.797. The gaps, 0.123 and 0.109 normalised units, are large relative to the
particle gap of 0.025, consistent with the construction in
\Cref{apx:non_equivalence_proof} where the event-period loss gap is proportional
to $M$. The proof is a sufficient-condition argument using a linear-Gaussian
model; it does not require the benchmark to match that structure exactly, but the
qualitative mechanism, event sensitive channels dominating forecast loss during
event periods, is present in the benchmark data.
\end{remark}
```
