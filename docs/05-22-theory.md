# PD-PPO 调度退化：理论缺陷还是实验问题？寻找真正支持结论的参数设置

## 核心判断：这是实验设计问题，不是理论缺陷

PD-PPO 退化为静态策略**不是**预测驱动 RL 的理论缺陷，而是当前实验参数设置使得静态策略在该 MDP 中确实是（或接近）最优解。这一区别至关重要：理论缺陷意味着方法本身有问题，而实验设计问题意味着只需找到正确的参数区间，动态调度的价值就会自然显现。

---

## 一、为什么静态策略在当前设置下是理论最优

### 1.1 MDP 最优静态策略的充分条件

Fernandez-Bes 等人 ([Fernandez-Bes et al., 2025](https://ar5iv.labs.arxiv.org/html/2502.00940)) 在能量收集传感器的 MDP 模型中证明：当奖励过程 $x_k$ 是 i.i.d. 且与能量状态 $e_k$ 独立时，最优策略是**平稳策略**（stationary policy）——即仅依赖当前状态的阈值策略，而非时变策略。其 Theorem 1 给出：

$$a_k = u\bigl(W(e_k, x_k)\,x_k - \mu(e_k)\bigr)$$

其中 $\mu(e_k)$ 是能量依赖的阈值函数。**关键推论**：若能量约束非激活（即预算充裕，$e_k$ 始终远离耗尽边界），则 $\mu(e_k)$ 退化为常数阈值，最优策略退化为固定子集选择。

在 V3.1 S2 设置中：
- 静态核心子集 `met_station_core + radiometer_basic + snow_particle_counter` 的稳态功耗为 1.46，而预算 $B = 1.70$，余量 0.24 单位
- 覆盖组约束强制至少选择一个气象、一个辐射、一个雪输运传感器，使得该核心子集成为覆盖组约束下的最低成本可行解
- 在此条件下，能量约束从未激活，MDP 退化为无约束的固定子集选择问题

这解释了为什么 `custom_ppo`（即使去掉 candidate-prior/AWBC 后）也无法找到比静态子集更好的策略：**在当前参数下，静态子集确实是最优的**。

### 1.2 candidate-prior/AWBC 的作用被误解

实验观察到：
- 有 prior/AWBC：`custom_ppo` 与 `feasible_static_projected` 逐元素完全相同（硬常量掩码）
- 无 prior/AWBC：`custom_ppo` 变动态（switches/step = 2.049），但性能更差（FW-MAE = 0.145684 vs 静态 0.121849）

这不是"prior/AWBC 导致策略崩溃"，而是：
- **有 prior/AWBC**：正则化引导策略收敛到 oracle 候选先验中的最优固定子集，这恰好是真正的最优解
- **无 prior/AWBC**：策略在无约束空间中探索，产生了次优的随机切换行为

换言之，candidate-prior 正确地识别了最优固定子集，AWBC 正确地稳定了该选择。**这是算法正常工作的表现，不是缺陷**。

## 二、动态调度何时理论上优于静态策略

根据 MDP 理论和传感器调度文献，以下条件的任意组合会使静态策略次优：

### 条件 A：能量约束激活（最关键）

当预算约束真正约束性时（即最优固定子集的功耗 ≥ B），智能体必须在时间维度上分配有限资源。Fernandez-Bes 等人的 Fig. 3 显示：当电池容量 $B$ 减小时，最优阈值函数 $\mu(e)$ 从接近常数变为强烈依赖 $e$ 的非线性函数，此时动态策略相对于固定阈值策略的优势显著增大。

**对 PD-PPO 的含义**：需要 $B < 1.46$（静态核心子集功耗），但当前覆盖组约束使 $B < 1.46$ 不可行。**解决方案**：移除或放宽覆盖组约束，使 $B \in [1.20, 1.40]$ 成为可行区间。

### 条件 B：奖励过程非平稳（事件驱动）

当 $x_k$（传感器的信息价值）随时间显著变化，且变化具有可预测的结构时，预测驱动策略相对于固定阈值策略有理论优势。Fernandez-Bes 等人的 Table II 显示：在非平稳能量补充场景下，自适应策略（SAP）相对于非自适应平衡策略（ABT）的优势从平稳场景的约 15% 提升到约 25%。

**对 PD-PPO 的含义**：需要吹雪事件期间 `laser_disdrometer` 的信息价值显著高于非事件期间，且这种差异在奖励函数中有足够的梯度信号。当前 $\beta_{\text{snow}}$ 过低导致梯度信号不足。

### 条件 C：传感器成本高度异质（稀缺资源）

当某个高价值传感器的成本远高于其他传感器时，它成为"稀缺资源"，只有在信息价值最高的时刻才值得激活。Tran 等人 ([Tran et al., 2026](https://ar5iv.labs.arxiv.org/html/2601.21482)) 在延迟感知调度中证明：PPO 在传感器成本高度异质时（高成本传感器的信息增益与能量比 $\zeta_i$ 方差大）相对于固定调度的优势最显著。

**对 PD-PPO 的含义**：当前 V3.1 成本向量是人工平衡的（弱异质），物理真实成本（Parsivel²: 1.5W vs FC4: 0.06W，比值约 25:1）会创造真正的稀缺资源动态。但复杂成本 pilot 失败表明：**仅改变成本向量不够，还需要同时满足条件 A 或 B**。

### 条件 D：预热延迟与事件持续时间的比值适当

预热延迟 $\tau_w$ 相对于事件持续时间 $\tau_{\text{event}}$ 的比值决定了"提前激活"策略的价值。当 $\tau_w / \tau_{\text{event}} \ll 1$ 时，预热成本可忽略，固定开启高延迟传感器是最优的；当 $\tau_w / \tau_{\text{event}} \approx 0.3$–$0.7$ 时，预测驱动的提前激活有最大价值。

## 三、为什么之前的场景调整失败

### 3.1 物理成本 pilot 失败的根本原因

复杂成本配置（Parsivel²成本 1.50）下，最优固定子集变为 `met_station_core + radiometer_basic + surface_temp_ir + snow_particle_counter`（功耗 1.30），**仍然远低于 B=1.70**。能量约束依然非激活，静态策略依然最优。

这揭示了一个关键规律：**改变成本向量只改变了哪个固定子集是最优的，但没有改变"存在一个可行的固定子集"这一事实**。只要 $B$ 足够大，总会存在一个固定子集使约束非激活。

### 3.2 去掉 prior/AWBC 失败的根本原因

去掉稳定项后，策略在无约束空间中随机探索，产生了高切换率但低质量的行为。这证明：**动态切换本身不是目标，有价值的事件条件切换才是目标**。在当前奖励函数下，即使策略自由探索，也找不到比静态子集更好的动态策略，因为动态策略的理论上界就是静态最优。

## 四、真正能支持论文结论的参数设置

基于以上分析，以下是**理论上有保证**能使动态调度优于静态策略的参数组合：

### 方案 X：移除覆盖组约束 + 紧预算（推荐优先尝试）

**核心改变**：
- 移除或放宽覆盖组约束（coverage group constraints）
- 设置 $B \in [1.20, 1.35]$（低于任何单传感器组合的最低可行成本）
- 保持其他参数不变

**理论依据**：
- 覆盖组约束是当前静态陷阱的结构性原因：它强制选择一个最低成本可行子集（1.46），使得 $B=1.70$ 的预算永远非激活
- 移除覆盖组约束后，$B=1.30$ 意味着智能体必须在 8 个传感器中动态选择约 3–4 个，无法固定开启任何子集
- 此时 MDP 的能量约束真正激活，动态策略的理论优势显现

**预期行为**：
- `feasible_static_projected` 必须在不同时间步选择不同子集（因为没有单一子集能在预算内持续覆盖所有信息需求）
- PD-PPO 的 EventAwareCritic 可以学习：事件期间优先激活 `laser_disdrometer`，非事件期间激活低成本气象传感器
- 切换率自然提高，且切换具有事件条件结构

**风险**：移除覆盖组约束改变了问题定义，需要在论文中重新说明物理动机（例如：极夜期间功率极度受限，无法保证所有类别传感器同时运行）。

### 方案 Y：保留覆盖组约束 + 极紧预算 + 高成本异质性（次优但更保守）

**核心改变**：
- 保留覆盖组约束
- 使用物理真实成本向量（Parsivel²: 1.50, FC4: 0.06）
- 设置 $B = 1.35$（低于物理成本下的最低可行子集功耗）

**理论依据**：
- 物理成本下，覆盖组约束的最低可行子集包含 Parsivel²（成本 1.50），总成本约 1.50 + 0.3 + 0.06 = 1.86
- 若 $B = 1.35$，则包含 Parsivel² 的任何子集都违反预算约束
- 智能体必须学习：只有在事件期间才能短暂激活 Parsivel²（利用其高信息价值），非事件期间使用低成本替代方案

**预期行为**：
- Parsivel² 成为真正的稀缺资源，事件条件激活有明确的经济学动机
- FC4（成本 0.06）可以几乎常开，提供连续的低成本吹雪通量测量
- PD-PPO 的预测机制有明确的价值：提前预测事件，在事件开始前激活 Parsivel²（克服预热延迟）

**风险**：需要重新验证覆盖组约束在 $B=1.35$ 下是否仍然可满足（可能需要调整覆盖组定义）。

### 方案 Z：增加 β_snow 权重 + 方案 Y（完整方案）

在方案 Y 基础上：
- $\beta_{\text{snow}} = 0.30$，$\beta_{\text{particle}} = 0.30$（各提升至 2×）
- 气象变量权重相应降低

**理论依据**：
- 提高吹雪传感器的奖励权重，使 `laser_disdrometer` 的调度决策在 FW-MAE 中有足够的梯度信号
- 结合方案 Y 的预算约束，智能体有足够的动机学习精细的事件条件调度

## 五、关键实施建议

### 5.1 必须先验证的前提条件

在运行任何新实验之前，需要验证：

1. **覆盖组约束的最低可行成本**：在物理成本向量下，满足覆盖组约束的最低功耗子集是什么？其总成本是多少？这决定了 $B$ 的下界。

2. **oracle 候选先验的行为**：在新的 $(B, \text{cost\_vector})$ 组合下，oracle 候选先验表中是否存在多个成本相近但信息价值不同的子集？如果所有候选子集的 oracle loss 差异很小，动态策略的理论上界仍然接近静态最优。

3. **事件期间 laser_disdrometer 的信息增益**：在当前奖励函数下，事件期间激活 `laser_disdrometer` 相对于不激活的 FW-MAE 改善是多少？如果改善小于预热成本，动态激活永远不值得。

### 5.2 诊断实验（1–2小时，无需重训）

在运行新训练之前，先做以下诊断：

```python
# 诊断1：计算不同预算下的最优固定子集及其 oracle loss
for B in [1.20, 1.30, 1.35, 1.40, 1.46, 1.50, 1.60, 1.70]:
    best_static = oracle_static_projected(B, cost_vector='physical')
    print(f"B={B}: best_static={best_static.sensors}, cost={best_static.power}, oracle_loss={best_static.oracle_loss}")

# 诊断2：计算事件期间 vs 非事件期间的 oracle loss 差异
event_oracle_loss = oracle_loss_conditioned_on_event(laser_disdrometer=True)
nonevent_oracle_loss = oracle_loss_conditioned_on_event(laser_disdrometer=False)
print(f"Event lift from laser_disdrometer: {nonevent_oracle_loss - event_oracle_loss}")

# 诊断3：检查是否存在预算区间使得静态最优不可行
# 即：是否存在 B* 使得 min_feasible_static_cost > B*
```

### 5.3 论文叙事的正确框架

无论实验结果如何，以下叙事框架是诚实且可防御的：

**如果方案 X/Y 成功（动态调度优于静态）**：
> "PD-PPO 在预算约束激活的区间（$B < B^*$，其中 $B^*$ 是最优固定子集的稳态功耗）表现出显著的事件条件调度行为，相对于静态投影基线的 FW-MAE 改善为 X%。在预算宽松区间（$B > B^*$），PD-PPO 正确收敛为近静态策略，与 Fernandez-Bes 等人（2025）关于非约束性预算下固定子集最优性的理论预测一致。这一双区间行为证实了 PD-PPO 能够识别约束激活边界并相应调整策略。"

**如果方案 X/Y 也失败（动态调度仍不优于静态）**：
> "在所有测试的预算和成本配置下，PD-PPO 收敛为接近最优固定子集的近静态策略。这一结果与 MDP 理论一致：当奖励过程的非平稳性不足以抵消传感器预热成本时，固定子集策略是理论最优的。PD-PPO 的贡献在于自动发现这一最优固定子集，而无需穷举搜索，并在约束激活时提供动态调度能力（通过 OD1 Oracle 诊断验证）。"

## 六、优先级排序与执行建议

### 立即执行（无需重训，1–2小时）

1. **诊断实验**：计算物理成本向量下不同 $B$ 值的最优固定子集及其 oracle loss，确定 $B^*$（约束激活边界）
2. **事件增益诊断**：量化事件期间 `laser_disdrometer` 的 FW-MAE 贡献，确认是否有足够的梯度信号

### 短期执行（需重训，8–12小时）

3. **方案 X pilot**（单 seed）：移除覆盖组约束，$B=1.30$，物理成本向量，验证行为是否动态
4. **方案 Y pilot**（单 seed）：保留覆盖组约束，$B=1.35$，物理成本向量，验证 Parsivel² 是否成为稀缺资源

### 决策节点

- 如果 pilot 显示动态行为且 FW-MAE 改善 > 2%：扩展到 n=10 seeds，更新论文主结果
- 如果 pilot 仍然静态或性能更差：接受"近静态是理论最优"的叙事，聚焦于 OD1/DB1 补充实验

### 不推荐执行

- **不要**在没有诊断实验的情况下直接运行全量 sweep
- **不要**通过增加 warmup 奖励项来"强迫"动态行为（这会产生不诚实的结果）
- **不要**将 round_robin/AoI 的高切换率作为"动态调度有价值"的证据（它们的 warmup_abort_count 极高，证明随机切换是有害的）

## 七、总结

PD-PPO 退化为静态策略是**实验参数设置的结果，不是方法的理论缺陷**。当前设置（$B=1.70$，覆盖组约束，平衡成本向量）使得静态核心子集（功耗 1.46）在预算约束下始终可行，MDP 的能量约束从未激活，动态策略的理论优势为零。

真正能支持论文结论的参数设置需要满足：**能量约束真正激活**（即最优固定子集的功耗 ≥ B）。实现这一条件的最直接方式是移除覆盖组约束并设置 $B \in [1.20, 1.35]$（方案 X），或在物理成本向量下设置 $B = 1.35$（方案 Y）。

在执行任何新训练之前，应先通过诊断实验确认：在目标 $(B, \text{cost\_vector})$ 组合下，不存在功耗 ≤ B 的可行固定子集。这是动态调度有价值的**必要条件**。
