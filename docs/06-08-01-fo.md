# 理论与公式分析报告

**论文：** *Prediction-driven reinforcement learning for power-limited sensor scheduling in cold-region monitoring*  
**作者：** Yongzhe Li, Zhuyu Zhang（东南大学）  
**分析范围：** 全部理论命题、数学公式、算法描述及代码实现的一致性

---

## 总体评估

论文的理论框架整体自洽，核心公式推导无根本性错误。但经逐条核查，发现若干**值得关注的问题**，涵盖：命题证明的逻辑缺口、公式定义的不完整性、符号使用的不一致性、以及代码实现与论文描述之间的偏差。以下按严重程度分级列出。

---

## 一、命题与证明中的问题

### 1.1 Proposition 1（静态分配器可以很强）——缺少正式证明，且前提条件过强

**原文命题：**
> Consider a fixed instantaneous budget, time-invariant sensor costs, no intertemporal energy state, and a forecast loss whose expected reduction from a sensor subset does not depend on hidden future regimes beyond the current stationary distribution. If warm-up and switching costs are nonnegative, an optimal policy for the expected one-epoch objective can be represented by a fixed feasible subset.

**问题：**

该命题的核心前提"forecast loss whose expected reduction from a sensor subset does not depend on hidden future regimes beyond the current stationary distribution"实际上是在假设**平稳性（stationarity）**，即预测损失的期望减少量与时间无关。在这一假设下，命题的结论（最优策略可由固定子集表示）几乎是平凡的——它等价于说"在平稳环境中，最优静态策略存在"，这是一个标准的有限动作空间最优化结论，无需额外证明。

然而，论文随后在实验中测试的正是**非平稳**场景（漂雪事件的稀疏发生），这与命题前提直接矛盾。论文在 Remark 中承认"The proposition is not used as a formal proof of optimality for the full simulator. It is a design warning."，但这一说明本身揭示了一个逻辑问题：**一个依赖平稳性假设的命题，被用于为非平稳实验中静态分配器的强竞争力提供理论依据，论证链条存在断裂。**

更严格地说，命题缺少对"one-epoch objective"与"multi-epoch discounted objective $J_{\mathrm{fcst}}(\pi)$"之间关系的说明。单步最优不蕴含多步折扣最优，尤其在有暖机延迟（warm-up latency $\tau_i$）的情况下，切换代价的跨期影响无法被单步分析捕捉。

**建议：** 将命题的适用范围明确限定为"单步期望目标"，并在 Remark 中补充说明该命题对多步折扣目标的局限性。

### 1.2 Proposition 2（预测驱动奖励的非等价性）——证明草图存在逻辑跳跃

**原文证明草图（主文）：**
> If the forecast target is $y_{t+1}=c z_t+M e_t+\eta_t$ with $M\gg c$, a schedule that refreshes only $z_t$ can have lower AoI or covariance trace while missing the intervals where $e_t=1$. A second schedule can accept older background measurements but pre-warm the event sensor, yielding lower forecast loss whenever the event term dominates.

**附录中的完整证明：**
> For non-event times, $\pi_1$ can have lower AoI and lower covariance trace because the background variable is fresher. During event times, however, the loss gap in the event term is proportional to $M$. For sufficiently large $M$, the expected forecast-loss reduction obtained by observing $e_t$ during events dominates the extra background error induced by the older $z_t$ measurement.

**问题一：AoI 的定义未给出，导致比较无法严格成立。**

论文定义了 AoI 目标函数 $J_{\mathrm{AoI}}(\pi) = -\mathbb{E}_{\pi}[\sum_{t,v} \mathrm{age}_{t,v}]$，但从未给出 $\mathrm{age}_{t,v}$ 的精确定义（例如，是自上次观测以来的步数，还是加权版本？）。在证明中，"$\pi_1$ can have lower AoI"这一断言依赖于 AoI 的具体定义。若 $\mathrm{age}_{t,v}$ 仅对被激活的传感器计数，则 $\pi_1$（始终激活背景传感器）的 AoI 确实更低；但若 AoI 对所有变量（包括事件变量）计数，则结论需要额外论证。

**问题二：协方差迹的比较缺少状态估计器的明确规格。**

"$\pi_1$ can have lower covariance trace"这一断言需要指定状态估计器（如卡尔曼滤波器）的具体形式。对于一般非线性估计器，协方差迹的大小与观测模式之间的关系并不直接。论文未给出估计器的数学规格，使得这一比较缺乏严格基础。

**问题三：证明仅建立了"存在性"，但命题声称的是"无单调变换"。**

命题声称"There is no monotone transformation that... orders schedules identically by prediction-driven reward, estimator covariance trace, and per-variable AoI."这是一个关于**所有可能单调变换**的全称否定命题，其证明需要排除所有单调变换的可能性。然而，附录中的证明仅构造了一对具体策略 $(\pi_1, \pi_2)$ 使得排序不同，这只能证明**特定的恒等变换不成立**，而不能排除存在某个非线性单调变换使得三种目标的排序一致。严格的证明应当说明：对于任意单调函数 $f$，存在策略对使得 $f(J_{\mathrm{AoI}}(\pi_1)) > f(J_{\mathrm{AoI}}(\pi_2))$ 但 $J_{\mathrm{fcst}}(\pi_1) < J_{\mathrm{fcst}}(\pi_2)$。由于单调函数不改变排序，这等价于直接证明排序不一致，即现有证明实际上已经足够——但命题的措辞（"no monotone transformation"）引入了不必要的复杂性，建议简化为"the three objectives do not induce the same ordering over feasible policies"。

### 1.3 Proposition 3（动作投影下的可行性）——证明草图引入了无关结论

**原文证明草图：**
> The executed action is the output of the feasibility projector, not the raw score vector. By construction, every projected mask belongs to $\mathcal{A}_{B}(t)$, so it satisfies the defining hard constraints. Since the action set is finite, a finite-horizon optimal deterministic feasible selector exists by standard backward induction over the projected action sets.

**问题：**

命题本身（"Any policy whose raw sensor scores are projected onto $\mathcal{A}_{B}(t)$ satisfies the constraints at every decision epoch"）是一个关于**可行性**的直接陈述，其证明只需说明"投影输出属于 $\mathcal{A}_{B}(t)$"即可，这由投影算法的构造直接保证。

然而，证明草图的最后一句"Since the action set is finite, a finite-horizon optimal deterministic feasible selector exists by standard backward induction over the projected action sets"引入了一个关于**最优性**的额外结论，而这并非命题所声称的内容。这一句话在逻辑上是多余的，且可能造成误解——读者可能误以为命题同时声称了最优策略的存在性。

此外，命题假设"$\mathcal{A}_{B}(t)$ is non-empty at every reachable scheduling epoch"，但论文未说明在何种条件下该假设成立（例如，是否存在一个始终满足预算约束的"空动作"或"最小激活集"）。在实际传感器配置中，若所有传感器的最小激活成本之和超过预算 $B$，则 $\mathcal{A}_{B}(t)$ 可能为空。

## 二、公式定义的不完整性

### 2.1 能量账户更新公式（Eq. 2）——符号 $c(a_t)$ 未完整定义

**原文公式：**
$$s_{t+1} = \min\{C, s_t + h - c(a_t)\}$$

**问题：**

$c(a_t)$ 被描述为"channel costs during an epoch"，但论文未给出其精确定义。根据代码实现（`env.py`），实际的能量消耗区分了**稳态功耗**（steady cost $p_i$）和**启动峰值功耗**（startup peak cost $p_i^{\mathrm{peak}}$），且两者在不同约束下分别检查。若 $c(a_t)$ 仅包含稳态功耗，则公式与启动峰值约束的处理方式不一致；若 $c(a_t)$ 包含启动峰值，则与 Eq. 1 中仅使用 $p_i$ 的瞬时预算约束不一致。

建议明确定义：
$$c(a_t) = \sum_{i: a_{t,i}=1} p_i + \sum_{i: a_{t,i}=1, a_{t-1,i}=0} p_i^{\mathrm{peak}}$$
或说明启动峰值是否计入能量账户。

此外，公式未处理 $s_{t+1}$ 的下界。论文提到"Actions that would drive $s_{t+1}<s_{\min}$ are clipped or rejected by an energy guard"，但公式本身只有上界 $\min\{C, \cdot\}$，缺少对 $s_{\min}$ 的显式处理。完整公式应为：
$$s_{t+1} = \min\{C, \max\{s_{\min}, s_t + h - c(a_t)\}\}$$
或说明"clipping"发生在动作选择阶段而非状态更新阶段。

---

### 2.2 预测加权 MAE（Eq. 3）——权重 $w_k$ 的归一化条件未说明

**原文公式：**
$$\mathcal{L}_{\mathrm{FW}}(t) = \sum_{k=1}^{H} w_k \frac{1}{|\mathcal{Y}|} \sum_{j \in \mathcal{Y}} \left| \hat{y}_{t+k,j} - y_{t+k,j} \right|$$

**问题：**

论文未说明权重 $w_k$ 是否满足归一化条件 $\sum_{k=1}^{H} w_k = 1$。若不归一化，则 $\mathcal{L}_{\mathrm{FW}}(t)$ 的量纲随 $H$ 变化，使得不同预测视野设置下的损失值不可比较。在实验部分，若 $H$ 作为超参数变化，则需要说明 $w_k$ 的归一化处理。

此外，$w_k$ 的具体取值（例如，是否为均匀权重 $w_k = 1/H$，或指数衰减，或近端加权）对实验结果有重要影响，但论文未在公式定义处给出，仅在实验配置中隐含。建议在公式定义处明确 $w_k$ 的形式或归一化条件。

---

### 2.3 预测驱动价值函数（Eq. 4）——折扣因子 $\gamma$ 与有限视野 $T$ 的关系未说明

**原文公式：**
$$J_{\mathrm{fcst}}(\pi) = \mathbb{E}_{\pi} \left[ -\sum_{t=0}^{T-1}\gamma^t \mathcal{L}_{\mathrm{FW}}(t) \right]$$

**问题：**

该公式将折扣因子 $\gamma$ 与有限视野 $T$ 同时使用，但未说明两者的关系。在标准 RL 理论中，有限视野 MDP 通常令 $\gamma=1$（无折扣），而无限视野 MDP 使用 $\gamma < 1$。若 $\gamma < 1$ 且 $T$ 有限，则公式在形式上是正确的，但需要说明为何在有限视野问题中引入折扣（通常是为了数值稳定性或与 PPO 实现保持一致）。

根据代码（`custom_ppo.py`），实际使用 $\gamma = 0.99$，这是标准 PPO 的默认值，适用于无限视野近似。但论文的实验是在有限长度的 episode（1024 步窗口）上进行的，此时 $\gamma = 0.99$ 会对远端奖励产生显著折扣（$0.99^{1024} \approx 4.4 \times 10^{-5}$），这意味着策略实际上主要优化近端预测质量，而非整个 episode 的平均预测质量。这一点对实验结果的解释有重要影响，但论文未加讨论。

---

### 2.4 AoI 目标函数（Eq. 5）——求和下标不一致

**原文公式：**
$$J_{\mathrm{AoI}}(\pi) = -\mathbb{E}_{\pi}\!\left[\sum_{t,v} \mathrm{age}_{t,v}\right]$$

**问题：**

$J_{\mathrm{AoI}}$ 的求和使用下标 $(t, v)$，其中 $v$ 应为变量（variable）的索引，但论文在其他地方使用 $j \in \mathcal{Y}$ 表示目标变量，使用 $i$ 表示传感器通道。下标 $v$ 未在符号表中定义，与全文其他符号体系不一致。

此外，$J_{\mathrm{AoI}}$ 的求和范围（$t$ 从 0 到 $T-1$，$v$ 从 1 到 $m$ 或 $d$？）未明确说明，而 $J_{\mathrm{fcst}}$ 使用了折扣因子 $\gamma^t$，但 $J_{\mathrm{AoI}}$ 没有，这使得两者在量纲和尺度上不可直接比较，削弱了 Proposition 2 的对比论证。

## 三、算法描述与代码实现的不一致性

### 3.1 PPO 目标函数——论文未给出显式公式

**问题：**

论文在第 4 节描述了 PD-PPO 框架，但**从未给出 PPO 裁剪代理目标（clipped surrogate objective）的显式数学公式**。这对于一篇以 PPO 为核心算法的论文而言是一个显著的遗漏。标准 PPO 目标为：
$$L^{\mathrm{CLIP}}(\theta) = \mathbb{E}_t \left[ \min\left( r_t(\theta) \hat{A}_t,\ \mathrm{clip}(r_t(\theta), 1-\varepsilon, 1+\varepsilon) \hat{A}_t \right) \right]$$
其中 $r_t(\theta) = \pi_\theta(a_t|s_t) / \pi_{\theta_{\mathrm{old}}}(a_t|s_t)$。

代码实现（`custom_ppo.py` 第 505–515 行）正确实现了上述公式，但论文正文中缺少对应的数学表达，读者无法从论文本身验证算法的核心设计。

### 3.2 总损失函数——代码包含论文未提及的额外项

**代码中的总损失（`custom_ppo.py` 第 529–536 行）：**
```
loss = policy_loss + vf_coef * value_loss - ent_coef * entropy
     + awbc_coef * awbc_loss + prior_kl_coef * prior_kl_loss
     + soc_aux_coef * soc_aux_loss
```

**问题：**

论文第 4.2 节仅提到"dominant reward term is $-\mathcal{L}_{\mathrm{FW}}(t)$; additional terms penalise excessive switching, coverage failure, and hard-constraint violation"，但代码中的损失函数包含三个论文未明确描述的额外项：

- **`awbc_loss`（Advantage-Weighted Behavioral Cloning Loss）**：这是一个模仿学习正则化项，将策略向贪心动作拉近，仅对正优势样本加权。论文完全未提及此项，但它可能对策略的收敛行为有重要影响。
- **`prior_kl_loss`（Prior KL Regularizer）**：将当前策略分布与先验分布（candidate prior）的 KL 散度作为正则化项。论文提到"candidate-prior information"，但未给出其在损失函数中的数学形式。
- **`soc_aux_loss`（State-of-Charge Auxiliary Loss）**：辅助预测 SOC 的损失项。论文未提及。

这三个额外损失项的存在意味着论文描述的训练目标与实际实现之间存在实质性差距，影响结果的可重复性。

### 3.3 奖励函数——事件乘数（event_multiplier）未在论文中定义

**代码中的奖励计算（`env.py` 第 214–227 行）：**
```python
event_multiplier = max(0.0, float(self.cfg.event_reward_multiplier)) if is_event else 1.0
base_loss = float(event_multiplier * float(oracle_loss ...))
```

**问题：**

代码在漂雪事件期间对基础损失乘以 `event_reward_multiplier`，这相当于在事件期间放大奖励信号，引导策略更重视事件期间的预测质量。这是一个重要的奖励工程设计，但论文第 3.4 节的奖励公式中完全未提及此乘数。若 `event_reward_multiplier > 1`，则实际优化目标与论文中定义的 $J_{\mathrm{fcst}}(\pi)$ 不同，后者对所有时步使用相同权重。

### 3.4 动作投影算法——论文声称满足"startup-peak constraints"，但代码逻辑存在潜在问题

**代码中的可行性检查（`power_projector.py` 第 110–118 行）：**
```python
steady, peak = self._power(indices, runtimes)
if self.constraints.per_step_budget is not None and steady > per_step_budget + 1e-12:
    return False
if self.constraints.startup_peak_budget is not None and peak > startup_peak_budget + 1e-12:
    return False
```

**问题：**

投影算法按**降序分数**贪心地添加传感器，每次添加前检查可行性。然而，这一贪心策略不保证找到**最优可行子集**（即在预算约束下最大化分数之和的子集），因为它是一个 0-1 背包问题的贪心近似。论文 Proposition 3 仅声称投影输出满足约束（可行性），并未声称最优性，这在技术上是正确的。但论文在描述动作投影时使用了"maps the scores to a binary action mask satisfying the current budget and startup constraints"，未说明这是近似最优而非精确最优，可能误导读者认为投影找到了最优可行动作。

此外，`_coverage_selection` 方法在贪心主循环之前强制满足覆盖约束，这意味着覆盖约束具有比分数排序更高的优先级。这一优先级设计未在论文中说明。

## 四、符号体系的不一致性

### 4.1 传感器索引与变量索引混用

论文使用 $i$ 表示传感器通道（$i = 1, \ldots, m$），使用 $j \in \mathcal{Y}$ 表示目标变量，使用 $v$ 表示 AoI 中的变量（未定义），使用 $d$ 表示真值状态的维度（$x_t \in \mathbb{R}^d$）。这四套索引体系在论文中交替出现，但它们之间的关系（例如，$|\mathcal{Y}| \leq d$，$m$ 与 $d$ 的关系）从未明确说明，增加了理解难度。

### 4.2 $\mathcal{A}_B(t)$ 的时变性未充分说明

论文将可行动作集记为 $\mathcal{A}_B(t)$（含时间下标 $t$），暗示其随时间变化。在固定预算、时不变传感器成本的情况下，$\mathcal{A}_B(t)$ 实际上不随 $t$ 变化（应记为 $\mathcal{A}_B$）。时间下标 $t$ 的引入可能是为了处理启动峰值约束（新激活的传感器有额外峰值功耗），但这一点未在符号定义处说明，导致符号的含义模糊。

**最需要优先修正的三个问题：**

第一，在第 4 节补充 PPO 裁剪代理目标的显式数学公式（问题 I1），这是算法论文的基本要求。第二，在第 4.2 节或附录中说明 AWBC 损失和 Prior KL 正则化项的数学形式及其在总损失中的作用（问题 I2），否则结果无法复现。第三，在第 3.4 节或第 4.2 节明确定义事件奖励乘数，并说明其与 $J_{\mathrm{fcst}}(\pi)$ 定义的关系（问题 I3），否则论文的优化目标与实验实现之间存在实质性不一致。
