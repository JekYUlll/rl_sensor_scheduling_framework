# PD-PPO 手稿终稿权威术语规范与领域校验词汇表

## 执行摘要

本报告仅以最新版 **`main(58).pdf`** 为审阅对象，覆盖正文、公式、符号表、算法、图中文字、图注、表头、表注、附录标题、补充材料交叉引用及参考文献中的读者可见术语。手稿当前已经建立了 `PD-PPO scheduler`、`PD-PPO policy`、`complete PD-PPO training configuration` 和 `reported implementation` 的基本区分，但仍存在三类需要在逐段精修前统一的问题：一是把普通开放复合词过度连字符化，例如 `behavior-cloning`、`forecaster-training` 和 `action-sequence`；二是使用了领域中不够标准的命名，例如 `minimum activation-duration constraint`、`Double-DQN` 和 `optional-channel capacity`；三是若干手稿自定义诊断名称没有通过公式或阈值获得独立定义，例如 `common channel-use diagnostic`、`sufficient observation dependence` 和 `intermediate overall selection frequency`。fileciteturn0file0

最重要的强制统一结论如下。

| 当前写法 | 终稿首选写法 | 结论 |
|---|---|---|
| `Double Deep Q-Network (Double-DQN)` | **Double DQN** | 必改。原始论文将算法表述为将 Double Q-learning 应用于 DQN，并不使用 `Double Deep Q-Network` 这一展开，也通常不写 `Double-DQN`。citeturn13search4 |
| `minimum activation-duration constraint` | **minimum dwell-time constraint** | 强烈建议必改。切换系统、混杂控制和 MPC 文献中的标准术语是 `minimum dwell time`。citeturn15search0turn15search3 |
| `remaining activation time` / `activation lock` | **remaining dwell time** / **dwell-time lock** | 与上述约束统一。 |
| `optional-channel capacity` | **cardinality constraint on optional channels** | 强烈建议改。有限数量传感器选择的标准优化术语是 `cardinality constraint`。citeturn15search6 |
| `candidate-set cardinality` | **cardinality constraint** | 必改，前者不是稳定的领域术语。 |
| `feasible-action mask` | **action mask**；需要强调语义时用 **feasibility-based action mask** | `action masking` 或 `invalid action masking` 是策略梯度文献中的标准名称。citeturn13academia51 |
| `look-ahead` | **lookahead**；对 \(c_t^{\mathrm{sup}}\) 更推荐 **future-condition supervision label** | 技术名词 `lookahead` 通常合写；手稿中的标签本质上是未来条件监督，而不是一般搜索算法的 lookahead。 |
| `behavior-cloning` | **behavior cloning** | 名词短语保持开放；只在必须消除前置修饰歧义时临时加连字符。PMLR/CoRL 文献广泛使用 `Behavior Cloning`。citeturn14search10turn14search11 |
| `generalized advantage estimate` 作为方法名 | **generalized advantage estimation (GAE)** | 原始方法名称是 estimation；单个计算结果才是 an advantage estimate。citeturn13search13turn13search14 |
| `startup-peak power` | **peak startup power** | 更符合英语工程名词顺序；`startup` 是过程，`peak` 修饰其功率。 |
| `changed-activation fraction` | **normalized Hamming distance between consecutive executed activation vectors**；短写 **normalized action-change rate** | 现有量已经由 Hamming distance 精确定义，不宜另造一个含义不透明的名称。Hamming distance 是两个等长向量不同位置数。citeturn12search6turn12search0 |
| `common channel-use diagnostic` | **不得保留为未定义术语**；改为具体判定名称或直接列公式 | 当前不是公认诊断名，也没有独立可复现定义。 |
| `condition-classification loss` | **future-condition classification loss** 或 **cross-entropy loss for future-condition classification** | 明确分类目标和实际损失函数。 |
| `event-balanced challenge window` | **event-balanced evaluation window** | `challenge window` 容易被理解为外部 benchmark challenge 或 adversarial stress test。 |
| `true-label baseline` | **privileged-label baseline** | 更准确地表达使用部署时不可获得的标签；避免让 `true` 暗示上界或最优策略。 |
| `basic radiometer` | **radiometer**，或在确认测量量后改为 **pyranometer** | `basic` 不是仪器学类别；若测量全球短波辐照度，通常应明确为 pyranometer。当前仪器类型不足，须标记为未指定。 |
| `FC4 blowing-snow flux sensor` | **FlowCapt FC4 acoustic snow-flux sensor** | 使用正式产品名和测量原理；FC4 是声学风驱雪输运传感器。citeturn6search1turn6search9 |

总体判断是：**PD-PPO 这一方法名可以保留；数学符号体系可以保留；大部分专业概念并非错误，但应显著减少不必要的连字符，并用标准控制、强化学习、传感器调度和寒区观测术语替换手稿自造表达。**

## 审核方法与全局统一原则

本次校验采用四层证据优先级。第一层是原始算法论文和官方会议页面，例如 PPO、GAE、Double Q-learning、动作掩码、行为克隆及多预测期时间序列预测；第二层是 IEEE、PMLR、ICLR、WMO 等机构或出版平台；第三层是控制、传感器调度和寒区测量领域的同行评审论文；第四层仅用于正字法判断的权威词典或编辑规范。PPO 的正式名称和 surrogate-objective 术语来自 Schulman 等人的原始论文；Double DQN 的名称来自 van Hasselt 等人的 AAAI 论文；`minimum dwell time` 来自切换系统与 MPC 文献；寒区现象定义以 WMO 为优先。citeturn13search0turn13search4turn15search0turn6search0

全文采用 **American English**：

| 类别 | 统一形式 | 禁止混用 |
|---|---|---|
| 拼写 | `behavior`, `optimization`, `modeling`, `normalized`, `labeled` | `behaviour`, `optimisation`, `modelling`, `normalised`, `labelled` |
| 论文自指 | `This paper`, `the study`, `the experiment`, `the evaluation` | `we`, `our method`, `our results` |
| 普通在线/离线 | `online`, `offline` | `on-line`, `off-line` |
| 时间序列 | `time series`；作普通定语仍保持开放，如 `time series forecasting` | `time-series forecasting`，除非出版社强制 |
| 地面真值 | 名词 `ground truth`；必要的前置临时复合修饰可写 `ground-truth data` | 全文机械地写 `ground-truth` |
| 启动 | `startup` | 在同一稿件中混用 `start-up` |
| 预热 | 名词和定语均用 `warm-up`；动词用 `warm up` | `warmup`, `warmup time` |
| 预测前视 | 技术名词和定语用 `lookahead` | `look-ahead`、`look ahead label` |
| 后选择 | `post-selection` | `postselection`，除非目标期刊明确要求闭合 |
| 多预测期 | `multi-horizon` 或 `multihorizon` 二选一；本稿推荐 **multi-horizon** | 与 `multi-step` 无规则地交替 |

英语复合词的总规则是：**已稳定成为领域术语的形式优先；普通名词短语默认开放；只有在前置复合修饰会产生真实歧义时才加连字符；数字加单位作前置定语时加连字符；对等概念间关系使用 en dash，而不是 hyphen。** Merriam-Webster 和通行技术编辑规范都强调，开放复合词不应仅因为位于名词前就机械地全部连字符化，尤其是已经不会误读的技术名词。citeturn11search3turn11search7turn11search8

例如：

- `behavior cloning loss` 不会被误读，无需写成 `behavior-cloning loss`。
- `22-seed analysis` 中数字与名词共同修饰 `analysis`，应保留连字符。
- `condition–channel mutual information` 表示两个对等变量之间的关系，应使用 en dash。
- `condition-specific weight` 是由名词和后缀构成的稳定复合形容词，可保留连字符。
- `forecast loss` 是开放名词短语；只有在 `forecast-loss-based` 这类多层修饰无法改写时才使用连字符。更自然的写法是 `reward based on forecast loss`。

引用文献标题、产品正式名称和作者姓氏不参与机械替换。例如参考文献中的 `continuous-discrete Kalman filtering`、论文原题中的连字符及 DOI/URL 字符串必须保持原样。

## 非标准、含糊或疑似 AI 生成式复合词

“疑似 AI 造词”不能被解释为能够证明某个语言模型创造了该表达。下表的判断标准是：该词在相邻领域缺乏稳定用法、由多个常见词机械拼接而成、无法仅凭名称恢复其统计定义，或与已有标准术语竞争。最安全的分类名称是 **manuscript-specific or nonstandard term**。

| 当前术语 | 风险等级 | 问题 | 现实领域替代方案 |
|---|---:|---|---|
| `minimum activation-duration constraint` | 高 | 切换控制领域已有标准 `minimum dwell-time constraint`；当前形式像对公式含义的机械直译。 | **minimum dwell-time constraint** |
| `candidate-set cardinality` | 高 | 不清楚是集合大小 \(K\) 还是动作中 active channels 数量约束。 | **cardinality constraint on optional channels** |
| `optional-channel capacity` | 中高 | `capacity` 可指带宽、能量或最大集合大小；此处实际是 cardinality upper bound。 | **optional-channel limit \(q\)** 或 **cardinality constraint** |
| `proposed-action credit` | 高 | 不是标准 RL credit-assignment 名称，且没有说明 buffer 保存什么 likelihood。 | **credit assignment to proposed actions during the dwell-time lock**；短写 **proposal-based credit assignment** |
| `executed-action PPO likelihood` | 高 | 容易误解为一种 PPO 变体。 | **policy likelihood of the executed action** |
| `common channel-use diagnostic` | 高 | `common` 没有可复现含义，且该“诊断”实际是多个 threshold criteria 的组合。 | 以实际代码定义命名，例如 **channel selection diversity criterion**，并列出完整逻辑 |

| `intermediate overall selection frequency` | 高 | `intermediate` 完全依赖未报告边界。 | **selection frequency in \([p_{\min},p_{\max}]\)** |
| `event-balanced challenge window` | 中高 | `challenge` 通常意味着专门 benchmark、stress test 或困难样本集；当前主要是按事件规则选择窗口。 | **event-balanced evaluation window** |
| `event-balanced challenge-window evaluation` | 高 | 三层临时复合，视觉和语义负担过大。 | **evaluation on event-balanced windows** |

建议将自动替换分为三个阶段。第一阶段只处理完全安全的正字法替换，例如 `Double-DQN`、`forecaster-training`、`behavior-cloning` 和 `ROC-AUC`。第二阶段处理需要语法调整的短语，例如 fixed baseline、forecast-loss reward 和 event-type-specific loss。第三阶段必须由代码和分析脚本反向核对，包括 diagnostics、instrument type、current power ratio、partition-boundary handling 和 warning metrics。

完成上述统一后，全文应遵循以下最终命名层级：

> **PD-PPO scheduler** 是完整方法；**PD-PPO policy** 是学习策略；**complete PD-PPO training configuration** 是经验结果的归因对象；**reported PD-PPO implementation** 用于讨论 proposed-action credit assignment 等代码特异性。

> **Candidate action set \(\mathcal A\)** 实施 mandatory-core 和 cardinality constraint；**feasible action set \(\mathcal F_t\)** 满足功率限制；**action mask** 将策略支持限制到 \(\mathcal I_t\)；**minimum dwell-time rule** 将 proposed activation vector \(\bar a_t\) 转换为 executed activation vector \(a_t\)。

> **\(L_{\mathrm{step}}\)** 是 time-step multi-horizon forecast loss；**\(L_{\mathrm{train}}\)** 是使用 calibration/validation data 规范化的 training loss；**\(R_t\)** 是 policy reward；**\(L_{\mathrm{macro}}\)** 是 evaluation-only macro-averaged normalized forecast loss。

> 四个数据分区固定为 **forecaster training partition**、**policy training partition**、**calibration/validation partition** 和 **test partition**；seed 集合固定为 **pilot seeds used for model selection**、**post-selection evaluation seeds**、**22-seed primary analysis** 和 **24-seed descriptive aggregate**。

> 寒区领域固定区分 **blowing snow** 与 **drifting snow**；仪器优先使用 **FlowCapt FC4 acoustic snow-flux sensor**、**laser-optical disdrometer**、**infrared surface temperature sensor** 和经实际 measurand 核实后的 **radiometer/pyranometer**。

在这一术语规范下，PD-PPO 方法名本身是可接受的手稿自定义专名；真正需要删除的是那些没有标准领域含义、没有数学定义或仅由多个名词机械拼接形成的中间表达。完成强制替换和未指定诊断的定义后，该术语表可以直接作为全文逐段精修、图表重导出、补充材料同步和自动 linting 的唯一 house style。
