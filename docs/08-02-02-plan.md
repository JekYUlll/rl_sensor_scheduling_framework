# PD-PPO 全文精修执行计划

本计划用于对最新版英文科研论文进行从头到尾的最终文风精修。每次恢复任务时，必须先重读 `docs/PD-PPO-TERMINOLOGY.md`、本计划和持久化进度记录，再继续修改 LaTeX 源文件。

本轮任务的核心是：

1. 严格统一全文术语；
2. 减少 AI 生成文本常见的措辞、句式和造词；
3. 提高学术表达的自然度、准确度、连贯性和可读性；
4. 保持现有技术内容、实验协议、证据边界和 claim 强度；
5. 使用客观学术主语，不使用第一人称复数；
6. 只进行文风与细节精修，不重新设计论文方法、实验或论证主线。

本轮由 Hermes 直接完成全部稿件修改、构建、集成和视觉核验。不得将正文、公式、表格、图源、补充材料、投稿附件或最终验证交给 Codex。非 Codex 子代理只允许执行只读审计。

- 两个 co-primary endpoints；
- comparator、metric、direction 和 temporal support；

- paired-difference sign convention 和 CI wording boundary；
- scheduler、policy、complete training configuration 和 implementation 的角色；
- deployment-available、training-only、calibration/validation-only、evaluation-only 和 privileged information；
- matched PPO scalar-objective comparisons、Double DQN training-configuration comparison 和真正 component ablation 之间的差异；

原稿已经完成协议、证据范围和限制条件的冻结。本轮禁止主动降低 claim。

必须保持原文中的：

六、减少 AI 风格
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

重点消除以下模式。

A. 空泛的引导语和评价语

尽量删除或改写：

- `It is worth noting that`
- `It should be noted that`
- `Importantly`
- `Notably`
- `Interestingly`
- `This distinction is important`
- `This change matters`
- `These findings highlight`
- `These results underscore`
- `Taken together`
- `In summary`
- `Overall`
- `In this context`
- `From this perspective`
- `It can be seen that`
- `It is clear that`

直接陈述事实或结论。

B. AI 常用动词

除非含义确实要求，减少：

- `leverage`
- `utilize`
- `facilitate`
- `enable`
- `enhance`
- `demonstrate the effectiveness of`
- `highlight`
- `underscore`
- `capture`
- `incorporate`
- `integrate`
- `provide insights into`
- `serve as`
- `play a crucial role`
- `offer a comprehensive`
- `address the challenge of`

优先使用直接领域动词：

- `use`
- `compute`
- `select`
- `apply`
- `evaluate`
- `compare`
- `define`
- `estimate`
- `measure`
- `restrict`
- `exclude`
- `retain`
- `update`
- `construct`
- `report`
- `show`

C. 机械对照句式

尽量避免：

- `A rather than B`
- `A instead of B`
- `not only A but also B`
- `A, while B`
- `A, whereas B`
- `Unlike A, B...`
- `Although A, B...`
- `On the one hand... on the other hand...`

需要表达差异时，优先拆成两句，直接说明各自作用。

示例：

不建议：
`The scheduler optimizes forecast loss rather than AoI.`

建议：
`The scheduler optimizes forecast loss directly. AoI is used only in the
comparison configuration.`

D. 冒号后机械列举

避免普通正文中出现：

`The method uses three components: A, B, and C.`

允许保留：

- 数学定义中的必要列举；
- 图注、表注和算法中的紧凑清单；
- 可复现性要求的参数列表；
- 正式 contributions enumerate 环境。

普通正文优先拆成自然句子。

E. 过度对称的并列

避免连续出现高度对称的：

- `A does X. B does Y. C does Z.`
- `First..., Second..., Third...`
- 三个长度和结构完全相同的分句；
- 为了形式整齐而重复相同谓语。

技术映射确实需要逐项对应时可以保留，例如 particle、flux、thermal 与传感器的明确对应。

F. 空泛抽象名词

减少：

- `framework`
- `pipeline`
- `mechanism`
- `paradigm`
- `strategy`
- `capability`
- `functionality`
- `dimension`
- `aspect`
- `perspective`
- `landscape`
- `workflow`
- `architecture-independent benefit`

优先使用具体对象：

- policy
- scheduler
- forecaster
- action set
- loss
- input
- update
- experiment
- comparison
- rule

G. 不必要的名词化

不建议：
`The execution of channel selection is performed by the policy.`

建议：
`The policy selects the channel subset.`

不建议：
`The computation of forecast loss is conducted by the forecaster.`

建议：
`The frozen primary forecaster computes forecast loss.`

H. 不必要的 AI 造词和连字符

严格按照【术语表】保留领域中真实常见的连字符。

【术语表】没有规定的多词概念，优先写成自然名词短语，避免临时拼接：

- 不主动创造新的 `X-based`
- 不主动创造新的 `X-aware`
- 不主动创造新的 `X-driven`
- 不主动创造新的 `X-oriented`
- 不主动创造新的 `X-specific`
- 不主动创造新的 `X-conditioned`
- 不主动创造新的 `X-informed`
- 不主动创造新的三段或四段连字符复合词

例如：

不建议：
`warning-conditioned, look-ahead-supervised training configuration`

优先：
`training configuration that uses warning signals and future-condition supervision`

不建议：
`validation-selected ridge-forecaster fixed-schedule baseline`

优先：
`fixed-schedule baseline selected with the ridge forecaster on the
calibration/validation partition`

七、自然学术英语规范
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

全文采用美式英语：

- optimization
- behavior
- modeling
- labeled
- normalized

优先使用短而直接的句子，但不要把段落拆成连续的电报式短句。

一句只承担一个主要判断。必要的限定条件可以保留在同一句中。

句子顺序通常遵循：

1. 已知背景或上一句对象；
2. 当前动作、定义或结果；
3. 条件、范围或限定；
4. 与下一句衔接的信息。

避免：

- 主语与谓语距离过远；
- 连续三个以上介词短语；
- 连续四个以上名词作前置修饰语；
- 一个句子中同时定义对象、说明原因、报告结果并讨论意义；
- 模糊的 `this`, `that`, `these`;
- 同一段中反复使用 `therefore`, `thus`, `consequently`;
- 同一段中连续使用多个 `which`, `where`, `while`;
- 无必要的被动语态。

技术术语允许重复。不要为了词汇多样性替换准确术语。

步骤 7：局部一致性检查

- 是否提前使用尚未定义的概念；
- 是否删除了后文依赖的铺垫。
