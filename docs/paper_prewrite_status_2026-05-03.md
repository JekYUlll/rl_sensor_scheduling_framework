## Important Corrections to `plan-05-03-1.md`

The plan still asks for DQN and CMDP-DQN rows in Table 2. The current v2 code
does not yet contain a DQN or CMDP-DQN implementation. The current paper-ready
Table 2 should therefore report:

- Full open unconstrained
- Feasible static projected
- Custom PPO
- Round robin
- AoI
- Random

DQN/CMDP-DQN must not be described as completed v2 experiments unless a new v2
implementation is added and run on the same grid.

The plan also states that all synthetic variables should pass `KS p > 0.05`.
The current validation file does not support that statement. In the locked
`budget=1.70, seed=41` validation:

- `air_temperature_c`, `relative_humidity`, and `air_pressure_pa` pass the KS
  threshold.
- `wind_speed_ms`, `wind_dir_sin`, and `wind_dir_cos` do not pass the stated KS
  threshold.
- Blowing-snow flux conditional rows are reported as conditional synthetic
  summaries rather than full real-vs-synthetic KS tests.

The manuscript should therefore describe Figure 3 as a transparency/diagnostic
figure for synthetic-data anchoring, not as proof that every variable is
statistically indistinguishable from AntAWS.
