## 一、统计显著性补充（最高优先级）

### 实验 S1：扩展随机种子并补充统计检验

**目标：** 将当前3个训练种子扩展至10个，在所有主实验结果上补充统计显著性检验，解决当前"提升幅度（0.012）小于标准差（±0.045）"的可信度问题。

**执行要求：**
- 对所有7个方法（Custom PPO + 6个基线）各运行10个独立随机种子（训练种子与评估种子均独立）
- 每个种子在100个评估回合上计算FW-MAE，得到每个方法的10个独立FW-MAE样本
- 在三个预算水平 $B \in \{1.65, 1.70, 1.75\}$ 下分别执行上述过程

**统计检验要求：**
- 对每个预算水平，以Custom PPO为基准，对每个基线方法执行双侧配对Wilcoxon符号秩检验（paired Wilcoxon signed-rank test），报告p值
- 同时报告95%自举置信区间（bootstrap CI，重采样次数≥10000）
- 显著性阈值设为 $\alpha = 0.05$，并应用Bonferroni校正（6个基线比较，校正后阈值为 $\alpha' = 0.0083$）

**输出数据格式：**
```

```

## 六、代码实现注意事项

**随机种子管理：** 训练种子和评估种子应分别独立设置，避免训练-评估种子相关性。建议使用如下约定：
```python
TRAIN_SEEDS = list(range(10))       # 0–9
EVAL_SEEDS  = list(range(100, 200)) # 100–199，与训练种子完全独立
```

**结果存储格式：** 所有实验结果以CSV格式存储，文件命名规范为 `exp_{实验编号}_{预算}_{时间戳}.csv`，便于后续统计分析脚本读取。

**统计检验实现：** 推荐使用 `scipy.stats.wilcoxon` 执行配对Wilcoxon检验，使用 `numpy` 实现自举置信区间。示例：
```python
from scipy.stats import wilcoxon
import numpy as np

def bootstrap_ci(data, n_bootstrap=10000, ci=0.95):
    bootstrapped = [np.mean(np.random.choice(data, len(data))) for _ in range(n_bootstrap)]
    lower = np.percentile(bootstrapped, (1 - ci) / 2 * 100)
    upper = np.percentile(bootstrapped, (1 + ci) / 2 * 100)
    return lower, upper

stat, p = wilcoxon(custom_ppo_scores, baseline_scores, alternative='two-sided')
```

**绘图库：** 推荐使用 `matplotlib` + `seaborn`，图表导出为PDF（矢量格式）和PNG（300 Dpi），以满足期刊投稿要求。字体统一使用 `Times New Roman` 或 `DejaVu Serif`，字号不小于9pt。
