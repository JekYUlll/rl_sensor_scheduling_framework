# V528 Specialist-Isolated Geometry Audit

This directory records the complete-subset geometry audit for Stage O. The
audit is diagnostic only; it does not contain a trained policy.

## Frozen protocol

- Truth seeds: `7181--7184`
- Frozen asset root: `reports/v527_specialist_isolated_assets_20260908/`
- Selectable devices: five entity-mapped instruments plus mandatory CR1000Xe
  backbone
- Feasible actions: all 16 masks generated by hard power/startup masking
- Steady/startup budgets: `2.15` / `2.60` effective-cost units
- Evaluator: frozen TCN prepared by the split-protocol asset command
- Audit command: `scripts/run_v528_specialist_isolated_geometry_20260908.sh`

## Decision metrics

The primary gate is the operating-state opportunity gap, defined as the
validation-selected static loss minus the weighted loss of the
operating-condition-wise best feasible subset. The required threshold was
`0.01` for every fresh seed, with no common epsilon-`0.01` subset.

| Seed | Event-label gap | Operating-state gap | Epsilon-0.01 operating intersection |
|---:|---:|---:|---|
| 7181 | 0.000000 | 0.000000 | candidate_003 |
| 7182 | 0.005421 | 0.000000 | candidate_005 |
| 7183 | 0.000000 | 0.000000 | candidate_005 |
| 7184 | 0.029224 | 0.000000 | candidate_003 |

The event-label gap is not the deployable gate. It uses privileged event
subtypes, whereas the operating-state partition is the chronological state
available to the scheduler. Stage O therefore fails the structural gate and
is closed before chronological transfer or PPO training.

lightweight audit artifacts. Full truth and model files remain on the data
volume and are not required for the repository diff.
