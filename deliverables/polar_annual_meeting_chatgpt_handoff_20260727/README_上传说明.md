# 极地年会中文汇报资料包

本目录供网页版 ChatGPT 制作一份 **15 分钟、22--23 页、中文、由导师汇报**
的学术 PPT。论文 PDF 和风格参考 PPT 已由用户另行上传，本包不重复收录。

## 最小上传组合

在论文 PDF 和风格参考 PPT 之外，优先再上传以下文件：

1. `markdown/08_给网页版ChatGPT的总提示词.md`
2. `markdown/02_23页逐页大纲.md`
3. `markdown/03_技术事实与数据口径.md`
4. `markdown/04_逐页讲稿与时间分配.md`
5. `images/01_极地多传感器平台渲染图_中文标注.png`

这组文件足以先生成逐页内容方案。

## 目录内容

- `markdown/`：汇报定位、逐页大纲、讲稿、术语、问答和总提示词。
- `images/`：可直接插入或据此重绘的高清 PNG/PDF。
- `data/`：经过核验的精简结果表及逐种子数据。
- `scripts/build_assets.py`：从冻结实验结果重建本包图表的脚本。

## 使用边界

- 主证据来自 24 个随机种子（117--140）的最终冻结实验。
- 场景是受南极自动气象站和风吹雪观测启发并校准的受控仿真，不是现场闭环验证。
- 汇报主线是“预测驱动的受约束传感器调度”，不应包装成通用 PPO 新算法。
- 不使用历史版本号、内部场景代号或已淘汰的旧实验。
- 不要把警报规则、真实事件标签参考或奖励替换实验放在主结论页。
